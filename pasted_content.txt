Build a production-ready **AI-Powered Student Academic Intelligence Platform** for my personal academic use.

The system should combine:

1. Live/authorized academic-data synchronization
2. Attendance intelligence
3. Eligibility prediction
4. Extra-class handling
5. Academic analytics
6. PDF/document learning assistant
7. AI exam preparation
8. Notifications and alerts
9. Personal academic dashboard

IMPORTANT:
- This must be an independent application.
- Do not impersonate or clone the university's official portal.
- Do not copy university logos, branding, proprietary assets, or official login pages.
- Use my own branding.
- Do not bypass CAPTCHA, authentication, access controls, or security mechanisms.
- Do not scrape data in a way that violates the university's terms or security controls.
- Live synchronization must use an authorized API, official export, approved integration, or user-provided data.
- Never store my university password in frontend code.
- Never fabricate academic data.
- Real imported/synchronized data must always be the source of truth.

1. LIVE ACADEMIC DATA SYNCHRONIZATION
==================================================

The most important requirement is that my dashboard should stay updated as my academic records change.

Architecture:

University/authorized data source
        ↓
Secure Integration/API/Import
        ↓
Backend
        ↓
Database
        ↓
AI/Data Processing
        ↓
Student Dashboard

Support these synchronization methods:

A. Official API
B. Authorized university integration
C. CSV/Excel export
D. JSON import
E. Manual upload
F. Optional browser-assisted sync only when explicitly permitted and technically supported

Create an abstraction layer:

```text
AcademicDataProvider
```

with methods such as:

```text
getStudentProfile()
getAttendance()
getTimetable()
getMarks()
getResults()
getAssignments()
getCredits()

```

This allows the real university API/integration to be connected later without redesigning the application.

Show:

```text

```

If synchronization fails:

```text
⚠ Last synchronization failed
Showing the latest successfully synchronized data.
```

Never pretend synchronization succeeded.

2. AUTOMATIC ATTENDANCE ENGINE
==================================================

Create a complete attendance intelligence engine.

For every subject calculate:

```text
Total Classes
Present
Absent
Current Attendance %
Required Attendance %
Remaining Scheduled Classes
```

Formula:

```text
Attendance % =
(Present / Total Classes) × 100
```

Make the required attendance threshold configurable.

Do not hard-code 75% as universally applicable.

Example:

```text
Required attendance: 75%
Current attendance: 68.42%
```

3. ATTENDANCE ELIGIBILITY CALCULATOR
==================================================

Create an interactive calculator.

User can enter:

- Current classes
- Present classes
- Absent classes
- Required percentage
- Expected remaining classes

Calculate:

### Classes required to become eligible

For current:

```text
Present = P
Total = T
Required = R
```

Find minimum additional classes x where:

```text
(P + x) / (T + x) >= R
```

Display:

```text
You need to attend X consecutive classes
to reach the required attendance.
```
